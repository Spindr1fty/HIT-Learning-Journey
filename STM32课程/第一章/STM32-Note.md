## 1-2： STM32简介
1. STM32是ST公司基于ARM Cortex-M内核开发的32位微控制器，ST是公司名，M是微控制器MicroController的首字母，微控制器就是MCU，就是我们常说的单片机，所以STM32也是一款单片机，32的意思是这是32位的单片机，相比较8位的51单片机，STM32的性能还是非常强的。ARM Cortex-M内核就是STM32内部的核心部分，这个内核是ARM公司设计的，它在STM32中占据极为重要的地位，相当于整个芯片的CPU  
2. STM32常应用在嵌入式领域，如智能车、无人机、机器人、无线通信、物联网、工业控制、娱乐电子产品等  
3. STM32功能强大、性能优异片上资源丰富、功耗低，是一款经典的嵌入式微控制器  
4. STM32 MCUs 32-bit Arm Cortex-M：  
HighPerformance：STM32F2 F4 F7 H7  
MainStream：STM32G0 G4 F0 F1 F3  
Ultra-Low-Power：STM32L4+ U5 L0 L1 L4 L5  
WireLess：STM32WL STM32WB  
本课程中学习使用到的为STM32F1，有177的内核跑分和72MHz的Cortex-M3内核  
5. ARM的介绍：  
- ARM既指ARM公司，也指ARM处理器内核
- ARM公司是全球领先的半导体知识产权(IP)提供商，全世界超过95%的智能手机和平板电脑都采用ARM架构
- ARM公司设计ARM内核，半导体厂商完善内核周边电路并生产芯片

7. 片上资源/外设

| 英文缩写 | 名称 | 英文缩写 | 名称 |
|---------|------|---------|------|
| NVIC | 嵌套向量中断控制器 | CAN | CAN通信 |
| SysTick | 系统滴答定时器 | USB | USB通信 |
| RCC | 复位和时钟控制 | RTC | 实时时钟 |
| GPIO | 通用IO口 | CRC | CRC校验 |
| AFIO | 复用IO口 | PWR | 电源控制 |
| EXTI | 外部中断 | BKP | 备份寄存器 |
| TIM | 定时器 | IWDG | 独立看门狗 |
| ADC | 模数转换器 | WWDG | 窗口看门狗 |
| DMA | 直接内存访问 | DAC | 数模转换器 |
| USART | 同步/异步串口通信 | SDIO | SD卡接口 |
| I2C | I2C通信 | FSMC | 可变静态存储控制器 |
| SPI | SPI通信 | USB OTG | USB主机接口 |

NVIC:内核里面用于管理中断的设备，比如配置中断优先级这些东西  
SysTick:是内核里面的一个定时器，主要用来给操作系统提供定时服务的，STM32是可以加入操作系统的，比如FreeRTOS、UCOS等，如果用了这些操作系统，就需要SysTick提供定时来进行任务切换的功能，本课程不需要操作系统，但是可以用这个定时器来完成Delay函数的功能  
RCC:可以对系统的时钟进行配置，还有就是使能各模块的时钟，在STM32中，其它的这些外设在上电的情况下默认是没有时钟的，不给时钟的情况下，操作外设是无效的，外设也不会工作，这样的目的是降低功耗。所以，在操作外设之前，必须要先使能它的时钟，这时就要用RCC来完成时钟的使能  
GPIO:GPIO是通用的IO口，我们可以用GPIO来点灯，读取按键等,是单片机最基本的功能  
AFIO:AFIO是复用IO口，它可以完成复用功能端口的重定义，还有中断端口的配置  
EXTI:EXTI是外部中断，配置好外部中断后，当引脚有电平变化时，就可以触发中断，让CPU来处理任务  
TIM:TIM是定时器，这也是整个STM32最常用，功能最多的外设，TIM分为高级定时器、通用定时器、基本定时器三种类型，其中高级定时器最复杂，常用的是通用定时器，这个定时器不仅可以完成定时中断的任务，还可以完成测速率、生成PWM波形，配置成专用的编码器接口等功能。像PWM波形，就是我们电机驱动、舵机驱动最基本的要求  
ADC:ADC是模数转换器，该STM32内置了12位的AD转换器，可以直接读取IO口的模拟电压值，无需外部连接AD芯片，使用非常方便  
DMA:DMA是直接内存访问，这个可以帮助CPU完成搬运大量数据这样的复杂任务  
USART:USART是同步或者异步串口，我们平常用的UART是异步串口的意思，这里的USART是既支持异步串口，也支持同步串口，实际上还是用异步串口比较多
I2C/SPI:是非常常用的两种通信协议，STM32也内置了它们的控制器，可以用硬件来输出时许波形，使用起来更高效，当然用通用IO口来模拟时许波形也是没有问题的  
CAN/USB:也是通信协议，CAN通信一般用于汽车领域，USB通信为生活中常用的通信协议，利用STM32的USB外设，可以做一个模拟鼠标、模拟U盘等设备  
RTC:是实时时钟，在STM32内部完成年月日、时分秒的计时功能，而且可以接外部备用电池，即使掉电也能正常运行  
CRC:CRC校验是一种数据的校验方式，用于判断数据的正确性，有了这个外设的支持，进行CRC校验就会更加方便  
PWR:PWR电源控制，可以让芯片进入睡眠模式等状态，来达到省电的目的  
BKP备份寄存器，这是一段存储器，当系统掉电的时候，仍然可由备用电池保持数据，这个可以根据其需要，完成一些特殊功能  
IWDG/WWDG:独立看门狗和窗口看门狗，当单片机因为电磁干扰死机或者程序设计不合理出现死循环的时候，看门狗可以及时复位芯片，保证系统的稳定  
DAC:数模转换器，它可以在IO口直接输出模拟电压，是ADC模数转换的逆过程  
SDIO:是SD卡接口，可以用来读取SD卡  
FSMC:是可变静态存储控制器，可以用于扩展内存，或者配置成其他总线协议，用于某些硬件的操作  
USB_OTG:是USB主机接口，用OTG功能，可以让STM32作为USB主机去读取其他USB设备  
*注：这是STM32F1整个系列的所有外设，并不是所有型号都拥有的全部的外设，如C8T6芯片，就没有后面的这四个外设*

9. STM32系统结构  
<img src="NoteImages/21.jpg" width="700">  
 
*图 STM32的系统结构图*  

左上角为Cortex-M3的内核，内核引出来了三条总线，分别是ICode指令总线、DCode数据总线、System系统总线，这个ICode总线和DCode总线主要是用来连接Flash闪存的；Flash里面存储的就是我们编写的程序，ICode指令总线就是用来加载程序指令的，DCode数据总线是用来加载数据的，比如常量和调试数据这些，除了ICode总线和DCode总线，内核还引出了System系统总线，System总线就连接到了这些其他的东西上面，比如SRAM，用于存储程序运行时的变量数据。对于FSMC，本课程的芯片不会用到，下面的这个AHB系统总线就是用于挂载主要的外设的，AHB的意思是先进高性能总线，挂载的一般是最基本的或者性能比较高的外设，比如复位和时钟控制这些最基本的电路；还有SDIO，也是挂载在AHB上的，再后来就是两个桥接，接到了APB2和APB1两个外设总线上，这个APB的意思是先进外设总线，用于连接一般的外设，因为AHB和APB的总线协议、总线速度、还有数据传送格式的差异，所以中间需要加两个桥接，来完成数据的转换和缓存，AHB的整体性能比APB高一些，其中这个APB2的性能又比APB1高一些，APB2一般是和AHB同频率，都是72MHz，APB1一般是36MHz，所以APB2连接的都是一般外设中稍微重要的部分，比如GPIO端口，还有一些外设的一号选手等，比如UASRT1、SPI1、TIM1、TIM8;TIM8和TIM1一样，也是高级定时器，所以也是重要的外设，还有ADC、EXTI、AFIO，也是接在APB2上面的。其他的像2、3、4、5号外设，还有DAC、PWR、BKP等，这些是次要一点的外设，都会分配到APB1上去。一般在使用的时候，个人一般感觉不到APB2和APB1的性能差异，只需要知道这个外设是挂载到哪个总线上的就可以了。右下角的这一大部分主要介绍的就是我们外设种类和分布。最后左下角的这一部分就是DMA,可以把DMA当作内核CPU的小秘书，比如有一些大量的数据搬运的活，让CPU来干的话就太浪费时间了

10. 芯片引脚定义
<img src="NoteImages/22.jpg" width="800">  
 
*图 STM32F103C8T6的引脚定义*  
标红色🟥的是电源相关的引脚，标蓝色🟦的是最小系统相关的引脚，标绿色🟩的是IO口、功能口这些引脚  
表头注解：  
引脚号和引脚名称：和上面的芯片引脚一一对应；  
类型：S代表电源，I代表输入，O代表输出，IO代表输入输出；  
I/O口电平：代表IO口所能容忍的电压，其中FT代表能容忍5V电压，没有FT的就只能容忍3.3V的电压，如果没有FT的需要接5V的电平，就需要加装电平转换电路；  
主功能：是上电后默认的功能，一般和引脚名称相同，如果不同的话，引脚的实际功能是主功能而不是引脚名称的功能；  
默认复用功能：是IO口上同时连接的外设功能引脚，在配置IO口的时候可以选择是通用IO口还是复用功能；  
重定义功能：改作用是，如果有两个功能同时复用在了一个IO口上，而使用者确实需要用到这两个功能，那可以把其中一个复用功能重映射到其他端口上，其前提是在重定义功能的表中有对应的端口  
引脚定义：  
`1.VBAT`引脚是备用电池供电的引脚，在该引脚可以接一个3V的电池，当系统电源断电时，备用电池可以给内部的RTC时钟和备份寄存器提供电源。  
`2.PC13-TAMPER-RTC`引脚是IO口或者侵入检测或者RTC，IO口可以根据程序输出或读取高低电平，是最基本也是最常用的功能；侵入检测可以用来做安全保障的功能，比如某产品的安全性比较高，可以在外壳加一些防拆触点，然后用电路与这个引脚相接，若有人强行拆开设备，触点断开，该引脚电平变化，就会触发STM32的侵入信号，清空数据来保证安全；RTC的引脚可以用来输出RTC校准时钟、RTC闹钟脉冲或者秒脉冲。  
`3.PC14-OSC32_IN`和`4.PC15-OSC32_OUT`引脚是IO口或者接32.768KHz的RTC的晶振。  
`5.OSC_IN`和`6.OSC_OUT`引脚接系统的主晶振，一般是8MHz，然后芯片内部有锁相环电路，可以对这个8MHz的频率进行倍频，最终产生72MHz的频率，作为系统的主时钟。  
`7.NRST`引脚是系统复位引脚，N代表它是低电平复位的。  
`8.VSSA`和`9.VDDA`引脚是内部模拟部分的电源，比如ADC、RC震荡器等，VSS是负极，接GND，VDD是正极，接3.3V.  
`10.PA0-WKUP`、`11.PA1`、`12.PA2`、`13.PA3`、`14.PA4`、`15.PA5`、`16.PA6`、`17.PA7`、`18.PB0`、`19.PB1`这些引脚都是IO口，其中PA0还兼具了WKUP的功能，这个可以用于唤醒处于待机模式的STM32。  
`20.PB2`引脚是IO口或者BOOT1引脚，BOOT引脚用来配置启动模式，另外🔸该IO口的引脚名称在图表中并没有加粗，其意味着推荐优先使用 10-19 IO口，在没有加粗标注的IO口中，可能需要进行配置或者兼具其他功能，使用的时候需要留意。  
`21.PB10`和`22.PB11`引脚也是IO口。  
`23.VSS_1`和`24.VDD_1`引脚是系统的主电源口，同样，VSS是负极，VDD是正极。  
`35.VSS_2`和`36.VDD_2`引脚以及`47.VSS_3`和`48.VDD_3`引脚，都是系统的主电源口，这里STM32内部采用了分区供电的方式，所以供电口会比较多，在使用的时候把VSS都接GND，VDD都接3.3V即可。  
`25.PB12`、`26.PB13`、`27.PB14`、`28.PB15`、`29.PA8`、`30.PA9`、`31.PA10`、`32.PA11`、`33.PA12`引脚都是IO口。  
`34.PA13`、`37.PA14`、`38.PA15`、`39.PB3`、`40.PB4`引脚，这些端口都是IO口或者调试端口，默认的主功能是调试端口，用来调试程序和下载程序，这个STM32支持SWD和JTAG两种调试方式，SWD需要2根线，分别是SWDIO和SWCLK；JTAG需要5根线，分别是JTMS、JTCK、JTDI、JTDO、NJTRST；在教程中使用的是STLink来下载调试程序，使用的是SWD的方式，所以只需要占用`34.PA13`和`37.PA14`这两个IO口，在使用SWD的调试方式时，剩下的`38.PA15`、`39.PB3`、`40.PB4`可以切换为普通IO口使用，但要在程序中进行配置，不配置的话默认是不会用作IO口的。  
`41.PB5`、`42.PB6`、`43.PB7`、`45.PB8`、`46.PB9`引脚都是IO口。  
`44.BOOT0`引脚和之前的BOOT1一样，也是用来做启动配置。  

11. STM32启动配置  
- BOOT0与BOOT1两根引脚的功能，该启动配置的作用是指定程序开始运行的位置，一般情况下，程序都是在Flash程序存储器开始执行
，但是在某些情况下，也可以让程序在别的地方执行，用以完成不同的功能  
- 在`STM32F10xxx`里，可以通过`BOOT[1:0]`引脚选择三种不同启动模式  
<img src="NoteImages/23.jpg" width="800">  
 
*图 启动配置*  
1.当BOOT0引脚为0时，即为接地的意思，这时BOOT1接X，无论接什么，启动模式都是主闪存存储器的模式，此时的主闪存存储器被选为启动区域，也就是正常的执行Flash闪存里面的程序，该模式是最常用的模式，一般情况下都为该配置。  
2.当BOOT1接0，BOOT0接1时，接1为接到3.3V电源正极，此时启动模式就是系统存储器，说明是系统存储器被选为启动区域，其实上该模式是用来做串口下载使用，系统存储器存的就是STM32中的一段BootLoader程序，BootLoader程序的作用就是接收串口的数据，然后刷新到主闪存当中，这样就可以使用串口下载程序，一般当需要串口下载程序的时候会配置到该模式上。  
3.BOOT1接1，BOOT0接1的时，这时配置的是内置SRAM启动，该模式主要用来进行程序调试，现阶段用的比较少，本课程也不会使用到  
🔸在系统复位后，SYSCLK的第4个上升沿，BOOT引脚的值将被锁存。用户可以通过设置BOOT1和BOOT0引脚的状态，来选择在复位后的启动模式  
*此句话意味着BOOT引脚的值是在上电复位后的一瞬间有效的，之后可以随便处置；在引脚定义图中可以看到，这个BOOT1和PB2是在同一个引脚上的，也就是在上电的瞬间，是BOOT1的功能，当第4个时钟过之后，其功能为PB2的功能*  

12. 最小系统电路  

<img src="NoteImages/24.jpg" width="700">  
 
*图 最小系统电路*  
一般来说，单片机只有一个芯片是无法工作，需要为它连接最基本的电路，这些最基本的电路就被称为最小系统电路  
1.STM32及供电：右边的部分为STM32及供电部分，其中该4个分区供电的主电源和模拟部分电源都连接了供电引脚，VSS都连接GND，VDD都连接3V3(3.3V)，在这个3.3V和GND之间，一般会连接一个滤波电容，这个电容可以保证供电电压的稳定，一般在设计电路的时候，只要遇到供电，都会习惯性的加上几个滤波电容，同时这个滤波电容也是非常重要的；VBAT是用来接备用电池，可以选择一个3V的纽扣电池，正极接VBAT，负极接GND即可，备用电池是给RTC和备份寄存器服务的，如果不需要该功能，就不用接备用电池，此时VBAT直接接3.3V或者悬空即可。  
2.晶振电路：此为一个典型的晶振电路，在此电路中接入了一个8MHz的主时钟晶振，STM32的主晶振一般都是8MHz，8MHz经过内部锁相环倍频，得到72MHz的主频，该晶振的两根引脚分别通过`OSC_IN`、`OSC_OUT`这两个网络标号，接到STM32的5、6号引脚，另外还需要接两个20pF的电容，作为起振电容，电容的另一端接地即可，此为晶振电路，如果需要RTC功能，还需要再接一个32.768KHz的晶振，其电路和这个一样，接在3、4号引脚，这个OSC32就是32.768KHz晶振的意思，至于为什么用32.768KHz，因为32768是2的15次方，内部RTC电路经过2的15次方分频，即可生成1秒的时间信号。  
3.复位电路：复位电路是一个10K的电阻和0.1μF的电容组成的，用来给单片机提供复位信号，在这中间的NRST接在STM32的7号引脚，NRST用来给低电平复位，当这个复位电路在上电的瞬间，电容是没电的，电源通过电阻开始向电容充电，并且此时电容呈现的是短路状态，NRST引脚就会产生低电平，当电容逐渐充满电的时候，电容相当于断路，此时NRST就会被R1上拉为高电平，上电瞬间的波形就是先低电平，然后逐渐高电平，此低电平可以提供STM32的上电复位信号，所以在使用者的角度，单片机在上电的一瞬间复位，这就是复位电路的作用；左边k处标记的地方可以提供一个手动复位的功能，当按下按键的时候，电容被放电，并且NRST引脚也通过按键被直接接地，相当于手动产生了低电平复位信号，按键松手之后，NRST又回归高电平，此时单片机就从复位状态转为工作状态；平时在设备上也可以看见这种复位按键，一般在设备上有个小孔，当设备死机且不方便断电重启的时候，可以拿针戳小孔里面的按键，使设备复位。  
4.启动配置：此处的H1相当于开关的作用，拨动此开关，就可以让BOOT引脚选择接3.3V还是GND了，在本课程学习的最小系统板上，使用的是这种跳线帽来充当开关的功能，当跳线帽插在左边的两个脚时，相当于接地，插在右边的两个脚时，相当于接3.3V，这样即可配置BOOT的高低电平。  

5.下载端口：需要把SWDIO和SWCLK这两个引脚引出来方便接线，另外把3.3V和GND引出来，其中GND为必须引出，3.3V如果板子有自己的供电，则可以不引，不过建议还是都将其引出，可以方便使用。
