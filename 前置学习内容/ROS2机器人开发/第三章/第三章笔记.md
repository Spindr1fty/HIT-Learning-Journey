## 话题通信介绍
1. 关键点  
小鱼（发布节点）--------{话题名称（鱼香ROS）、消息接口（图文、视频）}------------->读者（订阅节点）  
话题通信的四个关键点：  
发布者：小鱼        话题名称：鱼香ROS  
订阅者：读者        话题类型：图文、视频  
类型消息的类型属于消息接口，在消息接口中来定义

```bash
$ ros2 run turtlesim turtlesim_node

$ ros2 node info /turtlesim
---
/turtlesim
    Subscribers:
        /parameter_events: rcl_interfaces/msg/ParameterEvent/turtle1/cmd_vel: geometry_msgs/msg/Twist
    Publishers:
        /parameter_events: rcl_interfaces/msg/ParameterEvent/rosout: rcl_interfaces/msg/Log/turtle1/color_sensor: turtlesim/msg/Color/turtle1/pose: turtlesim/msg/Pose
```

` Subscribers: `为订阅者，表示该节点接收的话题  
```bash
/parameter_events
/rosout
/turtle1/cmd_vel    ← 接收速度指令，驱动小海龟移动
```
节点"听"这些话题。比如收到 cmd_vel 上的 Twist 消息就更新海龟位姿  

`Publishers：`为发布者，表示该节点发出的话题  
```bash
/turtle1/color_sensor   ← 海龟下方背景颜色
/turtle1/pose           ← 海龟当前位置和朝向
/parameter_events
/rosout
```
节点"说"这些话题。pose 常被其他节点订阅用于绘图或跟随  

`Service Servers`为服务，表示该节点提供的同步请求-相应接口  
```bash
/turtle1/set_pen     ← 设置画笔颜色/是否画线
/turtle1/teleport    ← 把海龟瞬移到指定位置
/parameter_events ...
```
Service Servers：本节点"提供服务"，别人调用它  
Service Clients：本节点"调用服务"，它去请求别人（如 /rosout 节点）  

`Action Servers`为动作，长耗时任务的异步接口  
```bash
/turtle1/rotate_absolute   ← 旋转到指定绝对角度

```
动作 = 目标 + 反馈 + 结果，适合"走几步路"这类需要中途反馈/可取消的长任务  
ROS2的四种通信方式：  
| 方式 | 特点 | 场景 | 
|------|----------|--------------|
| Topic | 多对多、异步、持续流 | 传感器数据、速度指令 |
| Service | 一对一、同步请求-响应 | 拍照、配置开关 |
| Action | 异步 + 进度反馈 + 可取消 | 导航到目标点 |
| Parameter | 运行时配置项 | 控制增益、阈值 |

也可以通过ROS2提供的命令行工具来实时查看话题的内容：  
```bash
$ ros2 topic echo /turtle1/pose
---
X: 5.544444561004639        //x值
y: 5.544444561004639        //y值
theta: 0.0
linear_velocity: 0.0        //线速度
angular_velocity: 0.0       //角速度

$ ros2 topic info /turtle1/cmd_vel -v
---
Type: geometry_msgs/msg/Twist       //类型
Publisher count: 0          //发布者数量
Subscription count: 1       //订阅者数量
Node name: turtlesim        //节点名称
Node namespace:/        //命名空间
Topic type: geometry_msgs/msg/Twist     //消息类型（也叫消息接口）
Endpoint type: SUBSCRIPTION
```
` ros2 topic echo `命令，功能为输出该话题的名字，` ros2 topic info `来查看话题信息  

如果知道一个消息接口，怎么去找到它这个消息接口的定义
```bash
Sros2 interface show geometry_msgs/msg/Twist
---
# This expresses velocity in free space broken into its linear and angular parts.
Vector3 linear
    float64 x
    float64 y
    float64 z
Vector3 angular
    float64 x
    float64 y
    float64 z

```
