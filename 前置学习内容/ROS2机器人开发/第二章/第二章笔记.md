 ## 2.1.2 编写你的第一个节点(C++示例)
 - 节点除了可以订阅和发布话题之外，还可以使用服务配置参数和执行动作等。  

 1. 打开虚拟机，打开虚拟机终端，在主目录下进入Chapt2文件夹(如果没有则自行创建即可)，并通过Chapt2文件夹的目录进入VSCODE,新建名为 ros2_cpp_node.cpp 文件  
 2. 前置说明 
 ```cpp
#include <iostream>
// argc为参数数量，char**双重指针，也可以理解为二维数组，argv为参数数组
using namespace std;
int main(int argc,char** argv)
{
    cout << "参数数量=" << argc << endl;
    cout << "程序名字=" << argv[0] << endl;
    return 0;
}
 ```
 ⭕记得保存文件后再运行  
在资源管理器的窗口右键，在集成终端中打开，因为只是一个单文件也没有什么依赖，所以先不用写CMakeList,直接使用g++就行  
通过argc和argv获取到我们输入的参数有几个同时第一个参数默认就是这个程序的名字
```bash
spindrift@spindrift-virtual-machine:~/Chapt2$ g++ ros2_cpp_node.cpp 
spindrift@spindrift-virtual-machine:~/Chapt2$  ./a.out
参数数量=1
程序名字=./a.out
spindrift@spindrift-virtual-machine:~/Chapt2$ ^C
spindrift@spindrift-virtual-machine:~/Chapt2$  ./a.out --help
参数数量=2
程序名字=./a.out
spindrift@spindrift-virtual-machine:~/Chapt2$ 
spindrift@spindrift-virtual-machine:~/Chapt2$ ./a.out --help 1 5 4
参数数量=5
程序名字=./a.out
spindrift@spindrift-virtual-machine:~/Chapt2$ 
```
输入--help时没有任何输出，是因为在程序里面没有对--help的后续参数进行处理，对后续的参数进行处理之后就可以输出，例如 ls 指令是查看文件列表， ls --help 是查看ls的帮助，为了要实现一样的效果，可以按以下操作:  
```cpp
    cout << "程序名字=" << argv[0] << endl; //在这一行下面加入
    string arg1 = argv[1];
    if(arg1 == "--help")
    {
        cout <<"这里是程序帮助，但是这个程序什么用都没有"<<endl;
    }
```
然后保存，编译后再运行就会得到--help的内容:  
```bash
spindrift@spindrift-virtual-machine:~/Chapt2$ g++ ros2_cpp_node.cpp 
spindrift@spindrift-virtual-machine:~/Chapt2$ ./a.out --help
参数数量=2
程序名字=./a.out
这里是程序帮助，但是这个程序什么用都没有
spindrift@spindrift-virtual-machine:~/Chapt2$ 
```
现在如果什么都不输，直接回车会报错，原因是在 argv[1] 非常常见的空指针异常，因为argv只有一个数据，就是a.out，后面没有加任何东西，在获取第一个数据的时候是错误的，最后将该文件备份为 test_args.cpp  
3. 完成ROS2的第一个节点的编写
```cpp
#include <rclcpp/rclcpp.hpp>
#include <iostream>
using namespace std;
int main(int argc,char** argv)
{
    // : 为域名解析符
    rclcpp::init(argc,argv);
    //auto为自动类型推导,在此创建一个rclcpp下的node的共享指针
    auto node = std::make_shared <rclcpp::Node> ("cpp_node");
    //这是一个宏定义
    RCLCPP_INFO(node.>get_logger(),"你好，C++节点");
    rclcpp::spin(node);
    rclcpp::shutdown();
    return 0;
}
```
这时使用g++会编译错误提示找不到头文件<rclcpp/rclcpp.hpp>，因为<iostream>为系统库的头文件，所以能找到，<rclcpp/rclcpp.hpp>为个人的头文件,要把rclcpp这个库导入到整个过程中，在此可以使用CMakeList来完成这个事情:  
1.打开Ubuntu的文件目录，找到Chapt1中的 CMakeLists.txt 并将其复制粘贴到 Chapt2 文件夹里面，然后进行改名:
```bash
cmake_minimum_required(VERSION 3.8)  
project(ros2_cpp)  
add_executable(ros2_cpp_node ros2_cpp_node.cpp)
```
