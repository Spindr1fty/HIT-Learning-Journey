## 1. 这个件是干什么的

**把 20kg 舵机固定在齿板（`dxf/gearban.dxf`，9mm 厚亚克力）上，让舵机的摆臂能带动发射机构。**

连接方式（用户确认）：舵机**躺放**，轴与齿板长边平行（沿 −X），法兰平面竖直，
4×M4 螺栓+螺母穿过两根立柱对锁；摆臂装在舵机花键上，平面 ⊥ 轴。

## 6. 重复踩过的 CAD 坑（写脚本时先看这段）

1. **圆柱钻孔必须用"中心对齐 + 放在壁中面"**：
   ```python
   # 对
   bd.Pos(W/2, y, z) * bd.Rot(0, 90, 0) * bd.Cylinder(r, L, align=(CENTER,)*3)
   # 错（MIN 对齐 + 旋转 → 刀跑到材料外，孔看着"没有"）
   bd.Pos(-1, y, z) * bd.Rot(0, 90, 0) * bd.Cylinder(r, L, align=(MIN, CENTER, CENTER))
   ```
   这个 bug 在同一个件上犯了 **3 次**，每次都是"用户说没孔"。
2. **三角形挤出也要"对称挤出 + 居中"**，否则法向跟着顶点绕向翻，筋会跑到零件外面。
3. **探针验证别用太小的方块 + 太松的阈值**（0.1mm 方块、阈值 0.001 会出假阳性）。
   现在统一用 **0.4mm 方块、阈值 0.004**，实心处约 0.064，孔内 0.000，差 160 倍。
4. **面贴面不会融合**——所有连接件必须重叠 ≥0.5mm。
5. **模型源码必须纯 ASCII**（cadgen 不指定编码，中文注释会炸）。
6. **cadgen 只在 `__main__` 里调用被装饰的函数时才写 STEP**；
   改完代码要重跑，必要时先删旧文件再生成。
7. **`\n` 别写在 PowerShell 双引号字符串里做替换** —— 会变成字面 `\n`，
   写进 Python 后整个语句被注释吃掉，报 NameError。要拆行就用 edit 工具。

## 9. 2026-10-19 晚：接手后的校验（rev 25 → rev 26）

### 9.1 修掉一个参考位错误：`SERVO_X` 30 → 37.5

`g_servo.py` 里法兰的上表面（舵机 Z=32.5）才是安装面（PROGRESS §12.1）。
它必须落在立柱内侧面 X=5 上 → `SERVO_X = 5 + 32.5 = 37.5`。
原来写 `SERVO_X = S.FLANGE_Z0 = 30`，法兰落在 **X −2.5~0**，即立柱前方 5mm，
那样 X=5 上的法兰槽什么也避让不到。**这只影响参考体/装配图，不影响正式件几何。**
### 9.2 rev 26：法兰槽 1.6 → 2.5（硬错误，已改）

`checks/mount_b_fit.py` 用 2.0 高的凸脊模型去撞槽：**共享 4.80 mm³**
（= 0.4 深 × 2.0 宽 × 3.0 长 × 2 根柱），即法兰被垫起 0.4mm。
凸脊 2.0 是用户实测（PROGRESS §10.2），Z 轴座那边同款让位缝就是 **2.5 深**。
所以 1.6 一定是笔误级别的不一致，已按 2.5 改，`newSTEP/g_mount_b.step` 已重出。
### 9.3 提案（未并入正式件）：立柱向外加宽 8 → 12

`src/g_mount_b_widepost.py`，**只改一个模块常量集，几何仍只有 g_mount_b.py 一份**。

| 项 | rev26 | 加宽提案 | 理由 |
|---|---|---|---|
| 立柱 Y | 21.94~29.94（8 宽）| 17.94~29.94（12 宽，只向外）| 40.5 净距与两条螺栓线都不动 |
| Ø4.5 孔边距 | 内 1.75 / 外 1.75 | 内 1.75 / 外 5.75 | 内侧由布局决定，改不了 |
| 三角筋腿长 | 9 | 5 | 柱外移 4 后仍落在底脚边 Y=12.94 |
| 体积 | 16.738 cm³ | 17.390 cm³（+0.65） | 加宽部分几乎全在现有三角筋里 |

**垫圈结论**：Ø9 垫圈在 4 个螺丝孔上都会顶到舵机本体（本体离螺栓线只有 4.25，
垫圈半径 4.5）→ **最多用 Ø8，或者不加垫圈**。M4 内六角头 Ø8.1（对角）
擦边 0.05，可接受；六角头（AF7）更安全。**拧紧力矩建议 ≤0.6 N·m**（PLA）。
