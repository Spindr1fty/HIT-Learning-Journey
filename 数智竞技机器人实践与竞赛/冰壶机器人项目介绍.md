# 冰壶机器人制作培训与激光切割实操-AI纪要

## 冰壶比赛规则与场地要求

- **场地分区与有效区域**
  - 场地分为两个区域，设有护栏；黄色区域为等待区，两队依次各出5个冰壶轮流击打
  - 浅蓝色区域为有效击打区，冰壶落在此区域内才算有效；落在白色区域或两侧边线外视为无效
  - 机器人本体可越过通信线，但冰壶不得过线

- **冰壶取放与尺寸限制**
  - 冰壶初始摆放在立体九宫格架上，排列为底层2个、中层2个、上层1个
  - 机器人需从九宫格上方将冰壶取下后再进行击打
  - 冰壶外形尺寸长宽必须小于350mm×350mm，避免防守时干扰其他机器人

- **得分判定与时间约束**
  - 得分规则为离中心最近的一方得分，仅该方计分；统计该方比对方最近壶更靠近中心的壶数量作为得分
  - 每轮抓取加击打的全套动作必须在2分钟内完成，结构设计需注重效率
  - 后手方具有战术优势，可在最后一投将对方壶打散并占据中心位置；比赛采用两场制，双方互换先后手

## 激光切割设备选型与软件配置

- **设备型号与功能区分**
  - 主要使用xTool P3二氧化碳激光切割机，适用于亚克力切割与打孔
  - xTool F2和U2为金属/非金属激光雕刻机，可用于制作Logo等精细图案，非本次机器人制作主力设备
  - 所有设备均可通过同一软件xTool Creative Space（叉兔）控制

- **软件设置与文件规范**
  - 绘图软件推荐卡萨2026或CAD，三维图可用solution works；二维图必须保存为DXF格式，其他格式设备无法识别
  - 软件中需选择设备型号为"P3"，连接方式为Type-C数据线；连接成功后设备指示灯变绿
  - 软件内置案例资源库，可下载齿轮等基础图形，但需根据实际机器人结构自行修改适配

- **材料规格与对焦处理**
  - 提供3mm和5mm两种厚度亚克力板，5mm强度更高；颜色提供黑色和白色
  - 透明亚克力因摄像头自动对焦反射不足易失准，需在表面贴白纸辅助对焦后再切割
  - 软件中选择材料厚度时必须与实际板材匹配，如4.7mm板材选5mm档位；选错厚度会导致切不透或功率异常

## 激光切割实操流程与安全规范

- **操作步骤与视觉识别**
  - 放料前需撕掉亚克力表面薄膜，防止切割起火或产生毛边影响精度
  - 工作台上6个视觉定位点不可被遮挡，否则设备无法识别板材位置
  - 开盖时红灯表示正在扫描，绿灯表示识别完成；识别未完成时不可合盖
  - 导入DXF文件后应将图形拖至板材左上角排版，避免浪费中间区域余料
  - 确认加工后需按下设备右侧唯一的大圆形按钮方可启动切割

- **安全注意事项与维护**
  - 激光切割必须在上课期间、有老师在场时使用，严禁无人值守运行；3D打印可课后继续运行但需确认首层无翘边
  - 设备配备二氧化碳自动灭火系统，检测到烟雾或火苗会自动喷射；遇小火苗切勿开盖
  - 切割完成后必须拔掉USB数据线再离开，避免拉扯损坏接口
  - 刀条下方积累的亚克力废料需定期用吸尘器清理，废料过多时应提醒讲师处理

## 设计绘图与加工工艺建议

- **激光切割优先原则**
  - 平面零件应优先使用激光切割而非3D打印；同等齿轮零件激光切割约2分钟完成，3D打印需3-5小时
  - 需要更厚结构时可将两层激光切割件叠加连接，避免依赖3D打印增厚
  - 仅在激光切割无法实现的特殊立体结构时才使用3D打印

- **机械结构设计技巧**
  - 圆轴传动时需将轴磨成D轴（一侧削平），对应孔也画成D形，防止轴与轮毂相对空转
  - 安装孔设计是激光切割件的核心用途，所有连接均依赖预留孔位配合螺钉螺母
  - 学员若不会二维或三维绘图，建议在组内指定专人学习CAD或卡萨，课程周期内掌握基础即可
